# Homework 1 — Matrix Algebra

This repository contains the manual solutions and NumPy verification code for Homework 1.

## Files

- `q1_basic_operations.py`: addition, subtraction, scalar multiplication, and matrix products.
- `q3_system.py`: solves the two-equation system using an inverse matrix.
- `q4_determinant_rank.py`: computes the determinant and rank of matrix C.
- `q5_inverse.py`: computes and checks the inverse of matrix D.
- `run_all.py`: runs all required Python checks.
- `Homework_1_Solutions.pdf`: complete black-and-white solution report.

## Run

```bash
python3 -m pip install -r requirements.txt
python3 run_all.py
```

The submitted report includes the GitHub repository URL.
